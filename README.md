# Hero-battle completed in Python
Its a turn based strategic battle game built with Tkinter, and Object-Oriented Programming (OOP).

# Key Features

**Custom UI:** Self-taught asset methods to import and display visual character images in VS Code/Tkinter.
**Robust Code:** Designed using Object-Oriented Programming (OOP) to handle game logic and player health cleanly.
**Project Resilience:** Served as the primary working code module to ensure final project delivery.
