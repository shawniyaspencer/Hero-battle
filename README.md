# Hero-battle

A turn-based strategic battle game built with Tkinter and object-oriented Python.

## Overview

Control a small party of heroes and defeat monsters. The UI uses Tkinter and Pillow for image support.

## Features

- Simple GUI built with Tkinter
- Object-oriented game classes (Hero, Monster)
- Image support via the Pillow library

## Requirements

- Python 3.8+
- Pillow

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run

From the repository root:

```bash
python "Project (6).py"
```

Notes:
- The project references local image files via an absolute path. To use images, update the GameApp.image_folder variable or place images in a folder and set the path accordingly.
